# 🎬 Movie Analysis Dashboard using Power BI

## 📌 Project Overview

The **Movie Analysis Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI**. The dashboard analyzes a movie dataset to uncover meaningful insights about movie performance, revenue, ratings, audience engagement, genres, and release trends.

This project demonstrates how raw data can be transformed into actionable insights using data cleaning, modeling, statistical analysis, DAX calculations, and interactive visualizations.

---

# 🎯 Project Objective

The primary objective of this project is to analyze movie data and provide meaningful business insights through interactive dashboards. The dashboard enables users to:

- Analyze overall movie performance.
- Identify the highest revenue-generating movies and genres.
- Study the relationship between ratings, audience votes, and revenue.
- Understand yearly trends in movie releases.
- Compare movie performance across different genres.
- Support data-driven decision making using visual analytics.
- Demonstrate Power BI reporting, dashboard design, and storytelling skills.

# 💡 Key Insights from the Project

### 📌 Revenue Insights
- Certain genres consistently generate higher revenue than others.
- Movies with higher audience engagement tend to earn more at the box office.
- Revenue trends vary significantly across different release years.

### 📌 Rating Insights
- High ratings do not always guarantee high revenue.
- Some lower-rated movies achieve strong commercial success.
- Average ratings remain relatively stable across most years.

### 📌 Audience Vote Insights
- Movies with a large number of audience votes generally perform better commercially.
- Audience engagement is positively correlated with revenue.

### 📌 Genre Insights
- Action, Adventure, and Drama are among the most successful genres.
- Some niche genres receive high ratings despite generating lower revenue.
- Genre popularity changes over time.

### 📌 Year-wise Insights
- Movie production has increased over recent years.
- Some years recorded significantly higher average revenue than others.
- Audience preferences evolve across different release periods.

### 📌 Correlation Insights
- Revenue is influenced by multiple factors rather than ratings alone.
- Audience votes show a stronger relationship with revenue than ratings.
- Genre and release year also contribute to movie performance.
